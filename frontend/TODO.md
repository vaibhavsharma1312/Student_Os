# Student OS Frontend Outcomes

- [x] **Authentication, student profile and skills:** Registration and login connect to the existing auth endpoints; profile setup/editing uses supported student fields; skill selection adds and removes skills through the existing API.
- [x] **Projects and join requests:** Students can browse project summaries, create projects using supported fields, inspect match/skill-gap insight, send join requests, and view/update project requests and statuses where the API permits.
- [x] **Opportunities and resources:** Students can browse available opportunities and resources, open their details, and create/manage owned items only where the backend provides those operations.
- [x] **Clear-English responsive workspace:** Provide a clear-English dashboard and responsive navigation, with useful loading, empty, error, and success states across the supported user flows.
- [x] **Configurable backend connection:** Provide a setting for the backend API base URL; browser requests use bearer authentication; keep backend hosting separate from the static frontend and include Vercel deployment instructions.
